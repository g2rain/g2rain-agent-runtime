# 架构差异与接入项

本项目已采用 API/Biz/Startup 三层结构，但以下接入项需随平台演进持续核验：

| 项目 | 当前约束 | 后续动作 |
| --- | --- | --- |
| 中央架构 Profile | 以 `java-domain-service 1.0.0` 为接入目标。 | 在正式发布前完成 Profile 一致性审核。 |
| 外部服务契约 | Studio、Model Nexus、MCP Registry 均通过公开契约协作。 | 为契约版本、超时和降级建立集成测试。 |
| 任务副作用 | 工具调用可能产生外部副作用。 | 为重试、恢复与去重策略补充可验证的端到端覆盖。 |
| 安全治理 | 配置和平台鉴权由环境及上游治理提供。 | 上线前确认服务身份、授权与审计链路。 |

本页记录已知差异和明确的接入任务，不把猜测当作已实现能力。
