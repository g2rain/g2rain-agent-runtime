# 核心运行流程

## 任务执行

1. 调用方提交会话或任务请求，Runtime 读取 Agent 配置与技能资料。
2. Runtime 构建计划和任务图，按节点选择模型或工具能力。
3. 节点调用经 Model Nexus 或工具回调完成，结果写入节点载荷、调用记录和任务状态。
4. Runtime 通过 SSE 发布过程事件；最终结果与收敛状态持久化。

## 中断与恢复

1. 在可恢复边界写入检查点和必要的状态快照。
2. 失败、取消或需要人工输入时记录恢复原因与可选动作。
3. 恢复请求校验任务状态和检查点，再从安全的边界继续；不得无依据地重放可能产生副作用的工具调用。

状态与事件的权威定义分别见 [STATE_SPEC.md](../STATE_SPEC.md) 和 [SSE_EVENTS.md](../SSE_EVENTS.md)。
