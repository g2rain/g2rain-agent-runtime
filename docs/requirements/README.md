# 需求设计与验收模板

每项运行时需求至少记录以下内容：

1. **目标与边界**：说明用户目标、非目标，以及是否涉及执行、恢复、对话、工具或模型调用。
2. **状态影响**：列出新增或变更的任务/节点状态、迁移条件、检查点和幂等语义；同步更新 `STATE_SPEC.md` 与状态图。
3. **接口与事件**：列出 HTTP、SSE、MCP 或服务间契约的请求、响应、错误及兼容性策略。
4. **安全与失败处理**：说明授权、敏感数据处理、超时、重试、取消、恢复和人工介入方式。
5. **验收条件**：包含成功路径、失败路径、恢复路径和可观测性断言。

涉及 Agent 配置、MCP 注册或模型供应商接入时，需求须明确对应责任仓库，不在 Runtime 内重复实现其管理职责。
