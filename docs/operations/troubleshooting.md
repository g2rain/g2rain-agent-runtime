# 故障排查

| 现象 | 检查顺序 |
| --- | --- |
| 服务无法启动 | 检查 profile、Nacos 连通性、数据源、Redis 和依赖服务配置。 |
| 任务停滞 | 使用任务/节点关联 ID 检查状态、检查点、恢复记录及模型/工具调用记录。 |
| SSE 中断或事件缺失 | 检查网关流式代理、客户端重连、事件终态与服务日志。 |
| 工具调用失败 | 核对 MCP 服务发现、工具 schema、授权、超时和调用记录。 |
| 恢复后出现重复副作用 | 停止盲目重试，检查工具调用幂等键、执行记录和人工确认策略。 |

排障输出必须脱敏。已知限制和待处理项见 [KNOWN_ISSUES.md](../KNOWN_ISSUES.md)。
